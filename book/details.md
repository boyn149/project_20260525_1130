# book_name: เสน่ห์เงียบฉบับ INFJ: ดึงดูดคนที่ใช่ด้วยหัวใจที่เป็นตัวเอง
# Philosophy 
หนังสือเล่มนี้ตั้งอยู่บนปรัชญาที่ว่าเสน่ห์ที่ทรงพลังที่สุดของผู้หญิงที่มีบุคลิกภาพแบบ INFJ ไม่จำเป็นต้องเกิดจากการเป็นฝ่ายรุกเสมอไป แต่คือความเข้าใจในธรรมชาติและคุณค่าของตนเอง โดยจะเป็นการนำทฤษฎีบุคลิกภาพ MBTI มาผสมผสานกับศาสตร์แห่งการดึงดูด (Art of Seduction) เพื่อสร้างกลไกแรงดึงดูดแบบ Passive Attractive ที่สามารถดึงดูดผู้คนเข้ามาได้อย่างลึกซึ้งและเป็นธรรมชาติ 
# Objective
1. เพื่อให้รู้กลไกการสร้างเสน่ห์ของผู้หญิง infj แบบไม่ต้องเป็นฝ่ายรุก 
2. เพื่อให้รู้ทันตัวเอง 
3. เพื่อให้สามารถดึงดูดคนที่รักได้ 
# Constrain
1. เนื้อหาต้องมีการพูดถึง type ของ mbti 
2. จำนวณ 1 บท 2 หัวข้อย่อย 
3. มีการเอา art of seduction เข้ามา 
4. มีรูปแทรก 
5. ใช้ RWP

# Philosophy 
การตัดความสัมพันธ์หรือปรากฏการณ์ "Door Slam" ไม่ใช่เพียงแค่อารมณ์ชั่ววูบ แต่เป็นกลไกการป้องกันตัวเองทางจิตวิทยาขั้นสุดท้ายของบุคลิกภาพแบบ INFJ หนังสือเล่มนี้มีจุดประสงค์เพื่อวิเคราะห์กระบวนการนี้อย่างเป็นเหตุเป็นผลผ่านหลักทฤษฎี MBTI เพื่อให้ผู้ที่มีความรู้ด้านจิตวิทยาเข้าใจถึงกระบวนการทำงานเบื้องหลัง และสามารถรู้เท่าทันกลไกการตัดสินใจของตนเองก่อนถึงจุดแตกหัก 
# Objective
1. เพื่อให้รู้กลไกการ door slam ของ infj 
2. เพื่อให้รู้ทันตัวเอง 
# Constrain
1. เนื้อหาต้องมีการพูดถึง type ของ mbti 
2. จำนวณ 1 บท 2 หัวข้อย่อย 
3. ไม่มีรูป 
4. ใช้ RWOP
